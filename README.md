# ContentXplorer-Dashboard

### Project Overview

ContentXplorer Dashboard is a data analytics and business intelligence project designed to analyze and compare the performance of content across multiple social media platforms. The project focuses on extracting meaningful insights from social media data using SQL for data analysis and Power BI for interactive data visualization.

The dashboard evaluates content performance across six major platforms: Instagram, YouTube, Facebook, LinkedIn, Twitter, and Snapchat. By analyzing engagement metrics, reach, impressions, views, and user interactions, the system helps identify which content strategies perform best and which platforms generate the highest audience engagement.

This project demonstrates how raw social media data can be transformed into actionable insights for digital marketing, content optimization, and strategic decision-making.

### 🎯 Objectives of the Project

The main objectives of the ContentXplorer Dashboard are:

To analyze social media performance metrics across multiple platforms.

To identify high-performing content categories and post types.

To compare engagement levels between different platforms.

To track monthly performance trends of content.

To measure audience interaction efficiency using engagement rate.

To support data-driven content strategy and marketing decisions.

### Database Design

The project follows a relational database structure consisting of three main tables:

1️⃣ Platform Table

This table stores information about the social media platforms included in the analysis.

Attributes:

Platform_ID (Primary Key) – Unique identifier for each platform

Platform – Name of the platform (Instagram, YouTube, Facebook, etc.)

2️⃣ Content Table

This table stores information about each piece of content posted on the platforms.

Attributes:

PostID (Primary Key) – Unique ID for each content post

PostType – Type of post (Video, Reel, Short, Live, Post)

Category – Content category (Education, Entertainment, Promotion, etc.)

PostDate – Date when the content was published

Platform_ID (Foreign Key) – Links the content to a specific platform

3️⃣ Performance Table

This table stores performance metrics and engagement statistics for each post.

Attributes:

Performance_ID (Primary Key) – Unique performance record ID

PostID (Foreign Key) – Links performance data to content

FollowerCount – Total followers of the platform

Views – Number of content views

Impressions – Total number of impressions

Reach – Unique users who viewed the content

Likes – Number of likes

Comments – Number of comments

Shares – Number of shares

Saves – Number of saved posts

ProfileVisits – Number of profile visits generated by the post

WatchTimeSeconds – Total watch time for video content

BounceRate – Percentage of users leaving quickly

Engagement – Combined engagement metric

CTR – Click-through rate

TrendingScore – Score representing content popularity

### 📈 Key Performance Metrics (KPIs)

The dashboard calculates several important metrics to evaluate content performance:

Total Posts

Total number of posts published on each platform.

Total Reach

The total number of unique users who saw the content.

Total Engagement

Total interactions including likes, comments, shares, and saves.

Engagement Rate (%)

Measures how effectively the audience interacts with the content.

Formula:

Engagement Rate = (Total Engagement / Total Reach) × 100
Total Views

Total number of views for video-based content.

Average Watch Time

Average time viewers spend watching video content.
